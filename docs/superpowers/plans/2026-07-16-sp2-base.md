# SP-2 — The Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a thin stage/DAG framework whose artifacts are content-addressed and version-stamped, and prove it by re-expressing the existing `ping-job` as the first real stage running end-to-end through the framework.

**Architecture:** A `Stage` is a near-pure async transform declaring `name`, `version`, and upstream `deps`. A pure `DagResolver` owns topology and staleness math. One generic `run_stage` Celery task, per stage, computes a content-addressed key, skips on a store cache hit, else runs the stage, validates + stores the body, records a `stage_run` row, and enqueues successors. A `document` + `stage_run` registry supersedes SP-1's `Job`.

**Tech Stack:** Python 3.13, FastAPI, Celery (prefork), SQLAlchemy 2 async + Alembic, MinIO (S3), Postgres, pytest + testcontainers. Managed by `uv`.

## Global Constraints

Every task's requirements implicitly include this section. Values copied verbatim from the SP-2 spec and SP-1's hard invariants.

- **Run tooling as `uv run --directory backend <cmd>`** — NEVER `uv --project` (selects the venv but not the cwd, so pytest/mypy silently find no config).
- **`fdi.core` is pure** — no I/O, config, clock, or RNG. CI-enforced by `lint-imports`: `api | workers → pipeline → platform → core`, `exhaustive = true`. Every new module must belong to a named layer.
- **Determinism (Global Constraint 6):** re-running a stage on the same input yields a byte-identical artifact body. No wall-clock, no RNG, stable sorts, pinned float formatting (SP-1 `canonical_json`). Ids and timestamps live in Postgres rows, never in the artifact body.
- **Canonical Celery task shape:** exactly one `asyncio.run()` per task; the async engine is built INSIDE the coroutine and disposed in `finally`; never build a loop/engine/pool at module import (fork copies it without its thread and hangs silently); never `async def` under `@app.task`.
- **Correlation id:** bound before `asyncio.run()`, cleared in `finally` (SP-1 machinery in `fdi.platform.obs.logging`).
- **Content-addressed + version-stamped:** artifact key = `artifacts/{doc_id}/{stage}/v{version}/{input_hash}.json`. A derived stage's `input_hash` is the sha256 over its upstream stages' recorded `output_hash` values (each `output_hash` = sha256 of that stage's stored canonical body). A root stage's `input_hash` = sha256 of the document's `checksum` (or `b""` while checksum is null).
- **Reject non-finite floats** at a pure validator before serialization; `canonical_json` stays a branch-free pass-through.
- **On Windows, prefix `lint-imports` with `PYTHONUTF8=1`** (PowerShell: `$env:PYTHONUTF8=1; ...`) or it dies rendering its report through cp1252 — a crash that exits 1 exactly like a broken contract.
- **`stage_run.status`** is constrained by an explicit `CHECK` to `('queued','running','done','failed')`; prove it bites with an insert of an illegal value expecting `IntegrityError`.

**Canonical commands:**
- Fast unit loop: `uv run --directory backend pytest -m "not integration and not e2e" -q`
- Integration (Docker): `uv run --directory backend pytest tests/integration -q`
- Gates: `uv run --directory backend ruff check .` · `uv run --directory backend mypy --strict src` · `$env:PYTHONUTF8=1; uv run --directory backend lint-imports --config .importlinter`

# backend/src/fdi/core/schema.py
"""Pure validation of artifact bodies. No I/O — belongs in fdi.core."""

import math
from typing import Final


class NonFiniteFloatError(ValueError):
    """A float in an artifact body is NaN or +/-Inf, so the body is not valid JSON."""


_PRIMITIVES: Final = (str, bool, int, type(None))


def validate_finite(obj: object, _path: str = "$") -> None:
    """Raise NonFiniteFloatError at the first non-finite float, else return None.

    bool is checked before int/float since bool is a subclass of int; it is always
    finite. int is exact. Only float can be NaN/Inf.
    """
    if isinstance(obj, bool) or obj is None or isinstance(obj, (str, int)):
        return
    if isinstance(obj, float):
        if not math.isfinite(obj):
            raise NonFiniteFloatError(f"{_path} is non-finite: {obj!r}")
        return
    if isinstance(obj, dict):
        for k, v in obj.items():
            validate_finite(v, f"{_path}.{k}")
        return
    if isinstance(obj, (list, tuple)):
        for i, v in enumerate(obj):
            validate_finite(v, f"{_path}[{i}]")
        return
    # Anything else (bytes, sets, custom objects) is not JSON-serialisable anyway.
    raise NonFiniteFloatError(f"{_path} is not a JSON value: {type(obj).__name__}")
```

"""Content-addressed artifact keys and the hashes that key them. Pure."""

import hashlib

from fdi.core.serialization import canonical_json_bytes


def output_hash(body: object) -> str:
    """sha256 of a body's canonical bytes — recorded per stage_run for downstream."""
    return hashlib.sha256(canonical_json_bytes(body)).hexdigest()


def root_input_hash(checksum: bytes | None) -> str:
    """Input hash for a stage with no upstream: the document's source checksum."""
    return hashlib.sha256(checksum or b"").hexdigest()


def derived_input_hash(upstream_output_hashes: list[str]) -> str:
    """Input hash for a derived stage: hash of its deps' output_hashes, in order."""
    joined = "\n".join(upstream_output_hashes).encode("utf-8")
    return hashlib.sha256(joined).hexdigest()


def artifact_key(doc_id: str, stage: str, version: int, input_hash: str) -> str:
    return f"artifacts/{doc_id}/{stage}/v{version}/{input_hash}.json"

# backend/src/fdi/pipeline/stage.py
"""The Stage contract. A stage is a near-pure async transform; the framework owns
all I/O, hashing, and persistence around it."""

from collections.abc import Awaitable, Callable
from dataclasses import dataclass
from typing import Protocol, runtime_checkable

ReadArtifact = Callable[[str, str], Awaitable[object]]


@dataclass(frozen=True)
class StageContext:
    """What a stage may touch: its document id, and a reader for upstream bodies."""

    doc_id: str
    read_artifact: ReadArtifact

    async def read(self, stage_name: str) -> object:
        return await self.read_artifact(self.doc_id, stage_name)


@runtime_checkable
class Stage(Protocol):
    name: str
    version: int
    deps: tuple[str, ...]

    async def run(self, ctx: StageContext) -> object: ...
```

"""A name -> Stage registry. Duplicate names fail here; topology is the resolver's job."""

from fdi.pipeline.stage import Stage


class StageRegistry:
    def __init__(self) -> None:
        self._stages: dict[str, Stage] = {}

    def register(self, stage: Stage) -> None:
        if stage.name in self._stages:
            raise ValueError(f"stage {stage.name!r} already registered")
        self._stages[stage.name] = stage

    def get(self, name: str) -> Stage:
        return self._stages[name]

    def all(self) -> dict[str, Stage]:
        return dict(self._stages)


REGISTRY = StageRegistry()

**Interfaces:**

- Produces: `class DagResolver`:
  - `__init__(self, stages: dict[str, Stage])` — validates every `dep` names a known stage (raise `ValueError`) and that there is no cycle (raise `CycleError(ValueError)`).
  - `successors(self, name: str) -> list[str]` — stages that list `name` in their `deps`, sorted.
  - `topological_order(self) -> list[str]` — all stages, deps before dependents, ties broken by name.
  - `plan(self, from_stage: str) -> list[str]` — `from_stage` plus its transitive successors, in topological order.
  - `stale(self, recorded: dict[str, "RunFacts"]) -> list[str]` where `RunFacts` is a `dataclass(version: int, input_hash: str, output_hash: str)`. A stage is stale if it has no record, OR `record.version != stage.version`, OR (for a derived stage) `record.input_hash != derived_input_hash([recorded[d].output_hash for d in deps])` (import from `fdi.pipeline.keys`). Root stages are stale only on missing record or version mismatch. Returns stale names in topological order.

# backend/src/fdi/pipeline/resolver.py
"""Pure DAG topology + staleness. No I/O: staleness is decided from recorded facts,
not by reading artifact blobs."""

from dataclasses import dataclass
from graphlib import CycleError as _GraphlibCycleError
from graphlib import TopologicalSorter

from fdi.pipeline.keys import derived_input_hash
from fdi.pipeline.stage import Stage


class CycleError(ValueError):
    """The registered stages form a dependency cycle."""


@dataclass(frozen=True)
class RunFacts:
    version: int
    input_hash: str
    output_hash: str


class DagResolver:
    def __init__(self, stages: dict[str, Stage]) -> None:
        for name, stage in stages.items():
            for dep in stage.deps:
                if dep not in stages:
                    raise ValueError(f"stage {name!r} has unknown dep {dep!r}")
        self._stages = stages
        # graphlib wants {node: predecessors}; deps ARE predecessors.
        self._sorter_graph = {n: set(s.deps) for n, s in stages.items()}
        try:
            self._order = list(TopologicalSorter(self._sorter_graph).static_order())
        except _GraphlibCycleError as exc:  # noqa: F841 - re-raised as our type
            raise CycleError("stage dependency cycle") from exc

    def topological_order(self) -> list[str]:
        # static_order already respects deps; make ties deterministic by name within levels
        return sorted(self._order, key=lambda n: (self._depth(n), n))

    def _depth(self, name: str) -> int:
        deps = self._stages[name].deps
        return 0 if not deps else 1 + max(self._depth(d) for d in deps)

    def successors(self, name: str) -> list[str]:
        return sorted(n for n, s in self._stages.items() if name in s.deps)

    def plan(self, from_stage: str) -> list[str]:
        keep: set[str] = set()
        frontier = [from_stage]
        while frontier:
            cur = frontier.pop()
            if cur in keep:
                continue
            keep.add(cur)
            frontier.extend(self.successors(cur))
        return [n for n in self.topological_order() if n in keep]

    def stale(self, recorded: dict[str, RunFacts]) -> list[str]:
        out: list[str] = []
        for name in self.topological_order():
            stage = self._stages[name]
            rec = recorded.get(name)
            if rec is None or rec.version != stage.version:
                out.append(name)
                continue
            if stage.deps:
                expected = derived_input_hash(
                    [recorded[d].output_hash for d in stage.deps]
                    if all(d in recorded for d in stage.deps)
                    else ["<missing>"]
                )
                if rec.input_hash != expected:
                    out.append(name)
        return out
```

import sqlalchemy
from sqlalchemy.ext.asyncio import AsyncSession

from fdi.core.facts import RunFacts
from fdi.platform.db.models import Document, StageRun


class RegistryRepository:
    def __init__(self, session: AsyncSession) -> None:
        self._s = session

    async def create_document(self, doc_id: str, checksum: str | None = None) -> None:
        self._s.add(Document(id=doc_id, checksum=checksum))
        await self._s.flush()

    async def start_run(
        self, run_id: str, doc_id: str, stage_name: str, stage_version: int,
        input_hash: str, correlation_id: str | None,
    ) -> None:
        self._s.add(StageRun(
            id=run_id, doc_id=doc_id, stage_name=stage_name, stage_version=stage_version,
            input_hash=input_hash, status="running", correlation_id=correlation_id,
        ))
        await self._s.flush()

    async def finish_run(self, run_id: str, output_hash: str, artifact_key: str) -> None:
        run = await self._s.get(StageRun, run_id)
        assert run is not None
        run.status, run.output_hash, run.artifact_key = "done", output_hash, artifact_key
        await self._s.flush()

    async def fail_run(self, run_id: str, error: str) -> None:
        run = await self._s.get(StageRun, run_id)
        assert run is not None
        run.status, run.error = "failed", error
        await self._s.flush()

    async def runs_for_document(self, doc_id: str) -> dict[str, RunFacts]:
        rows = (await self._s.execute(
            sqlalchemy.select(StageRun)
            .where(StageRun.doc_id == doc_id, StageRun.status == "done")
            .order_by(StageRun.created_at)
        )).scalars().all()
        facts: dict[str, RunFacts] = {}
        for r in rows:  # later done-run for a stage overwrites the earlier
            facts[r.stage_name] = RunFacts(r.stage_version, r.input_hash, r.output_hash or "")
        return facts

    async def latest_run(self, doc_id: str, stage_name: str) -> StageRun | None:
        return (await self._s.execute(
            sqlalchemy.select(StageRun)
            .where(StageRun.doc_id == doc_id, StageRun.stage_name == stage_name)
            .order_by(StageRun.created_at.desc()).limit(1)
        )).scalars().first()
```

# backend/src/fdi/pipeline/run.py
"""The framework around a Stage: hashing, the content-addressed cache, persistence,
and successor scheduling. A stage stays a pure transform; all of that lives here."""

from collections.abc import Callable
from contextlib import AbstractAsyncContextManager

from fdi.core.schema import validate_finite
from fdi.pipeline.keys import (
    artifact_key,
    derived_input_hash,
    output_hash,
    root_input_hash,
)
from fdi.pipeline.registry import StageRegistry
from fdi.pipeline.resolver import DagResolver
from fdi.pipeline.stage import StageContext
from fdi.platform.db.models import Document
from fdi.platform.db.repository import RegistryRepository
from fdi.platform.storage.artifact_store import ArtifactStore

SessionFactory = Callable[[], AbstractAsyncContextManager]


async def run_stage(
    *, doc_id: str, stage_name: str, run_id: str, correlation_id: str | None,
    session_factory: SessionFactory, store: ArtifactStore,
    registry: StageRegistry, resolver: DagResolver,
) -> list[str]:
    stage = registry.get(stage_name)

    async def read_artifact(d: str, upstream: str) -> object:
        async with session_factory() as s:
            run = await RegistryRepository(s).latest_run(d, upstream)
        assert run is not None and run.artifact_key is not None
        return await store.get_json(run.artifact_key)

    # 1. input_hash from recorded upstream output_hashes (root: document checksum).
    async with session_factory() as s:
        repo = RegistryRepository(s)
        facts = await repo.runs_for_document(doc_id)
        if stage.deps:
            input_hash = derived_input_hash([facts[d].output_hash for d in stage.deps])
        else:
            doc = await s.get(Document, doc_id)
            checksum = doc.checksum.encode() if doc and doc.checksum else None
            input_hash = root_input_hash(checksum)

    key = artifact_key(doc_id, stage_name, stage.version, input_hash)

    async with session_factory() as s:
        await RegistryRepository(s).start_run(
            run_id, doc_id, stage_name, stage.version, input_hash, correlation_id
        )
        await s.commit()

    # 2. cache hit: record and skip the body.
    if await store.exists(key):
        existing = await store.get_json(key)
        async with session_factory() as s:
            await RegistryRepository(s).finish_run(run_id, output_hash(existing), key)
            await s.commit()
        return resolver.successors(stage_name)

    # 3. cache miss: run, validate, store, record.
    try:
        body = await stage.run(StageContext(doc_id=doc_id, read_artifact=read_artifact))
        validate_finite(body)
        await store.put_json(key, body)
    except Exception as exc:
        async with session_factory() as s:
            await RegistryRepository(s).fail_run(run_id, repr(exc))
            await s.commit()
        raise
    async with session_factory() as s:
        await RegistryRepository(s).finish_run(run_id, output_hash(body), key)
        await s.commit()
    return resolver.successors(stage_name)

def run_stage_task(doc_id: str, stage_name: str, correlation_id: str | None) -> None:
    corr = correlation_id or new_correlation_id()
    bind_correlation_id(corr)
    try:
        run_id = f"{doc_id}:{stage_name}:{new_correlation_id()}"
        successors = asyncio.run(_run_stage_async(doc_id, stage_name, run_id, corr))
        for nxt in successors:
            run_stage_task.delay(doc_id, nxt, corr)
    finally:
        clear_correlation_id()
