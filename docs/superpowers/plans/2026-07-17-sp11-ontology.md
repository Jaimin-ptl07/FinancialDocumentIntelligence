# SP-11 — Ontology Mapping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Map financial line-item labels onto a closed `CanonicalConcept` set via a pure `map_label` +
`map_document` + an `OntologyStage` (`deps=("ast",)`) that chains off AST automatically. Dictionary-based
and deterministic for this thin slice — no LLM.

**Architecture:** `OntologyStage` reads the AST artifact (`ctx.read("ast")`) and returns
`{schema_version, mappings[{label, concept}]}` by running every section heading and paragraph through
`map_label` (normalize → dictionary lookup) and keeping only non-`UNKNOWN` results. Reuses SP-2's
derived-stage machinery (input_hash from the AST output_hash; auto-scheduled as a successor of `ast`) —
zero framework changes, same shape as SP-8's `AstStage` and SP-6's `NormalizeStage`.

**Tech Stack:** Python 3.13, the SP-2 framework, pytest + testcontainers, `uv`.

## Global Constraints

- `uv run --directory backend <cmd>` — NEVER `uv --project`.
- Import contract `api | workers → pipeline → platform → core`, `exhaustive`. `core` pure —
  `ontology.py` has no I/O (no LLM/HTTP import; `re` and `enum` only). `OntologyStage` in `pipeline`.
- Determinism: `map_label` and `map_document` are pure functions of their string/AST input; no LLM, no
  wall-clock, no RNG — a real, unconditional determinism property (unlike SP-10's semantic stage, which
  had to special-case non-determinism).
- On Windows prefix `lint-imports` with `PYTHONUTF8=1`.
- Integration tests: reuse `session_factory` + `store` fixtures; mint unique ids/checksums per test; use a
  LOCAL `StageRegistry` in the test (register `OcrStage` + `NormalizeStage` + `AstStage` + `OntologyStage`)
  rather than the global registry, to avoid cross-test coupling.

**Canonical commands:** fast `pytest -m "not integration and not e2e and not azure" -q`; integration
`pytest tests/integration -q`; gates `ruff check .` · `mypy --strict src` · `PYTHONUTF8=1 lint-imports --config .importlinter`.

### Task 1: `CanonicalConcept` + `map_label` (core, pure)

**Files:** Create `backend/src/fdi/core/ontology.py`; Test `backend/tests/unit/test_ontology.py`.

**Interfaces:** `class CanonicalConcept(StrEnum)` with `REVENUE`, `COST_OF_GOODS_SOLD`, `GROSS_PROFIT`,
`OPERATING_EXPENSE`, `NET_PROFIT`, `TOTAL_ASSETS`, `TOTAL_LIABILITIES`, `EQUITY`, `CASH`, `UNKNOWN` (each
value equal to its member name, per SP-10's `SectionType` convention). `_SYNONYMS: dict[str,
CanonicalConcept]` — the Indian-annual-report starter set (spec §3.2). `_normalize_label(label: str) ->
str` — lowercase, drop punctuation (`[^\w\s]` → `""`), collapse whitespace, strip. `map_label(label: str)
-> CanonicalConcept` — normalize then `_SYNONYMS.get(normalized, CanonicalConcept.UNKNOWN)`. Never raises.

### Task 2: `map_document` (core, pure)

**Files:** Modify `backend/src/fdi/core/ontology.py`; Test `backend/tests/unit/test_map_document.py`.

**Interfaces:** `map_document(ast: Mapping[str, object]) -> dict[str, object]` → `{"schema_version": 1,
"mappings": [{"label": <str>, "concept": <CanonicalConcept value str>}]}`. Walks `ast["sections"]`; for
each section, maps `heading` (if a non-empty match) then each `paragraphs` entry via `map_label`, keeping
only non-`UNKNOWN` results, in document order. Malformed/missing fields are skipped, never raised (mirror
`build_ast`'s defensive `isinstance` walk over `object`-typed data).

- [ ] **Step 1: Failing test**

from fdi.core.ontology import map_document

_AST = {
    "schema_version": 1,
    "title": "ACME LTD Annual Report",

        {"heading": "Balance Sheet", "paragraphs": ["Total Assets", "Total Liabilities"]},

}


def test_map_document_maps_headings_and_paragraphs() -> None:
    out = map_document(_AST)
    assert out["schema_version"] == 1
    assert out["mappings"] == [
        {"label": "Revenue", "concept": "REVENUE"},
        {"label": "Sales", "concept": "REVENUE"},
        {"label": "Total Assets", "concept": "TOTAL_ASSETS"},
        {"label": "Total Liabilities", "concept": "TOTAL_LIABILITIES"},
    ]


def test_map_document_no_sections_is_empty_mappings() -> None:
    assert map_document({}) == {"schema_version": 1, "mappings": []}
    assert map_document({"sections": []}) == {"schema_version": 1, "mappings": []}


def test_map_document_malformed_section_is_skipped() -> None:
