# SP-17 — Quality Validation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A pure quality-validation core (`fdi.core.quality`) that inspects an artifact for internal
defects and emits `{schema_version, issues, error_count, warning_count, ok}`, plus a `QualityStage`
(`deps=("ast",)`) that runs the AST validators and chains off `ast` automatically.

**Architecture:** `Issue = dict[str, object]` (`{severity, code, message}`); `Validator =
Callable[[Mapping[str, object]], list[Issue]]`. Four pure validators — `ast_has_sections`,
`sections_have_content`, `title_present` (AST) and `tables_are_rectangular` (structure, written now,
not yet wired into a stage — see spec §2.3). `validate(artifact, validators)` aggregates. `QualityStage`
reads `ctx.read("ast")` and returns `validate(ast, AST_VALIDATORS)`. Reuses SP-2's derived-stage
machinery (input_hash from the AST output_hash; auto-scheduled as a successor of `ast`).

**Tech Stack:** Python 3.13, SQLAlchemy/MinIO/Postgres via the SP-2 framework, pytest + testcontainers, `uv`.

## Global Constraints

- `uv run --directory backend <cmd>` — NEVER `uv --project`.
- Import contract `api | workers → pipeline → platform → core`, `exhaustive`. `core` pure —
  `quality.py` has no I/O. `QualityStage` in `pipeline`.
- Determinism: every validator and `validate` are pure functions of their artifact argument; ids/
  timestamps live in Postgres, never in the artifact.
- `mypy --strict`: index `object`-typed values (`ctx.read(...)` returns `object`; `Mapping[str,
  object].get(...)` returns `object`) via `isinstance`/`cast`, as `build_ast`/`merge_cross_page_tables`
  already do.
- On Windows prefix `lint-imports` with `PYTHONUTF8=1`.
- Integration tests: reuse `session_factory` + `store` fixtures; mint unique ids/checksums per test;
  use a LOCAL `StageRegistry` in the test (register `OcrStage` + `NormalizeStage` + `AstStage` +
  `QualityStage`) rather than the global registry, to avoid cross-test coupling.
- Registering a new global stage changes what `DagResolver(REGISTRY.all()).successors(...)` returns
  elsewhere in the suite — `successors("ast")` now includes `"quality"`. Check no existing test asserts
  `successors("ast") == [...]` as an exact list (membership assertions only); fix with a membership
  check if one does, as was done when `NormalizeStage`/`AstStage`/`StructureStage` were added.

```python
# backend/src/fdi/core/quality.py
"""Quality validation: pure validators over a document's own artifacts, checking
for internal defects (not correctness against ground truth -- see fdi.core.metrics
/ SP-3 for that comparison). No I/O; deterministic; validators compose via
`validate`."""

from collections.abc import Callable, Mapping, Sequence
from typing import cast

Issue = dict[str, object]
Validator = Callable[[Mapping[str, object]], list[Issue]]

_KNOWN_SEVERITIES = {"error", "warning"}


def _issue(severity: str, code: str, message: str) -> Issue:
    return {"severity": severity, "code": code, "message": message}


def ast_has_sections(ast: Mapping[str, object]) -> list[Issue]:
    sections = cast(list[object], ast.get("sections", []))
    if not sections:
        return [_issue("error", "ast.no_sections", "AST has no sections.")]
    return []


def sections_have_content(ast: Mapping[str, object]) -> list[Issue]:
    sections = cast(list[Mapping[str, object]], ast.get("sections", []))
    issues: list[Issue] = []
    for index, section in enumerate(sections):
        paragraphs = cast(list[object], section.get("paragraphs", []))
        if section.get("heading") is None and not paragraphs:
            issues.append(_issue(
                "warning",
                "ast.empty_section",
                f"Section at index {index} has no heading and no paragraphs.",
            ))
    return issues


def title_present(ast: Mapping[str, object]) -> list[Issue]:
    if ast.get("title") is None:
        return [_issue("warning", "ast.missing_title", "Document has no title.")]
    return []


def tables_are_rectangular(structure: Mapping[str, object]) -> list[Issue]:
    tables = cast(list[Mapping[str, object]], structure.get("tables", []))
    issues: list[Issue] = []
    for index, table in enumerate(tables):
        column_count = cast(int, table.get("column_count", 0))
        cells = cast(list[Mapping[str, object]], table.get("cells", []))
        torn = any(cast(int, cell.get("column_index", 0)) >= column_count for cell in cells)
        if torn:
            issues.append(_issue(
                "warning",
                "structure.torn_table",
                f"Table at index {index} has a cell referencing a column_index "
                f">= its column_count ({column_count}).",
            ))
    return issues


AST_VALIDATORS: tuple[Validator, ...] = (ast_has_sections, sections_have_content, title_present)


def validate(artifact: Mapping[str, object], validators: Sequence[Validator]) -> dict[str, object]:
    issues: list[Issue] = [issue for validator in validators for issue in validator(artifact)]
    for issue in issues:
        if issue["severity"] not in _KNOWN_SEVERITIES:
            raise ValueError(f"unknown issue severity: {issue['severity']!r}")
    error_count = sum(1 for issue in issues if issue["severity"] == "error")
    warning_count = sum(1 for issue in issues if issue["severity"] == "warning")
    return {
        "schema_version": 1,
        "issues": issues,
        "error_count": error_count,
        "warning_count": warning_count,
        "ok": error_count == 0,
    }
```

```python
# backend/src/fdi/pipeline/stages/quality.py
"""QualityStage: a DERIVED stage that validates the AST for internal defects
and emits a quality report. Auto-chains off AstStage via `deps=("ast",)`."""

from collections.abc import Mapping
from typing import cast

from fdi.core.quality import AST_VALIDATORS, validate
from fdi.pipeline.registry import REGISTRY
from fdi.pipeline.stage import StageContext


class QualityStage:
    name = "quality"
    version = 1
    deps: tuple[str, ...] = ("ast",)

    async def run(self, ctx: StageContext) -> object:
        ast = cast(Mapping[str, object], await ctx.read("ast"))
        return validate(ast, AST_VALIDATORS)


REGISTRY.register(QualityStage())
```
